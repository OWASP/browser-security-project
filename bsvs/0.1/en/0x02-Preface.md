# Preface

Web browsers have become the primary execution environment for modern applications. Most enterprise work now happens inside a browser, from email and documents to business-critical SaaS applications, financial systems, and AI-powered tools.

Despite this, browser security has historically been treated as a subset of endpoint or network security rather than a discipline in its own right. The result is a gap: organizations lack a structured, testable set of controls specifically addressing the browser layer.

The Browser Security Verification Standard (BSVS) fills this gap. It defines security requirements across eight domains, from governance and configuration management to AI and agentic browsing, that organizations can use to assess and improve their browser security posture.

## Who is this for?

- **Security teams** evaluating browser security controls and maturity
- **IT administrators** deploying and configuring browsers at scale
- **Auditors and assessors** verifying browser security as part of broader assessments
- **CISOs and security leaders** prioritizing browser security investments
- **Browser and security vendors** aligning products with enterprise security needs
