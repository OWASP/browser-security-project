# V1: Browser Governance, Ownership & Policy

## Control Objective

This chapter addresses organizational governance of browser security, including ownership, policy coverage, standards, and vendor management.

---

## V1.1 Ownership & Accountability

| # | Description | Level |
| :---: | --- | :---: |
| **1.1.1** | **Verify that** a named owner (role or team) is assigned responsibility for browser security policy and configuration across the organization. | 1 |
| **1.1.2** | **Verify that** browser security responsibilities are documented across endpoint, identity, network, and application security functions with defined handoffs. | 2 |
| **1.1.3** | **Verify that** browser risk is represented in the organization's risk register and reviewed on a defined cadence. | 2 |

---

## V1.2 Policy Coverage

| # | Description | Level |
| :---: | --- | :---: |
| **1.2.1** | **Verify that** an acceptable use policy covers browser usage, including sanctioned browsers, personal profile use, and extension installation. | 1 |
| **1.2.2** | **Verify that** policy defines which browsers and versions are approved for business use, and prohibits unmanaged browsers for access to sensitive systems. | 2 |
| **1.2.3** | **Verify that** policy addresses BYOD and unmanaged-device browser access to corporate resources, with technical enforcement defined. | 2 |
| **1.2.4** | **Verify that** GenAI usage via the browser (chatbots, sidebars, agents) is covered by policy, including data classification rules for what may be submitted. | 2 |

---

## V1.3 Standards, Exceptions & Review

| # | Description | Level |
| :---: | --- | :---: |
| **1.3.1** | **Verify that** a documented exception process exists for deviations from browser policy, with expiry dates and compensating controls. | 2 |
| **1.3.2** | **Verify that** browser security policies and configurations are reviewed at least annually and after significant browser platform changes. | 2 |
| **1.3.3** | **Verify that** browser controls are included in internal audit or independent assessment scope. | 3 |

---

## V1.4 Vendor & Procurement Governance

| # | Description | Level |
| :---: | --- | :---: |
| **1.4.1** | **Verify that** security requirements (including this standard) are considered when procuring enterprise browsers, browser security tooling, or browser-based SaaS. | 2 |
| **1.4.2** | **Verify that** third-party browser components (enterprise browsers, extension vendors) are covered by the organization's third-party risk process. | 3 |
